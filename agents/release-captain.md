# Release Captain

Package the run into judge-friendly evidence: risk report, MCP writeback plan, SQL guardrails, team board, and dashboard. The output should be runnable, reviewable, and easy to show in a sub-three-minute demo video.

Workflow:

1. Confirm the run has findings, proposals, and sample generated artifacts.
2. Produce sample SQL or code where useful.
3. Keep a team board with owners, state, acceptance criteria, and merge gates.
4. Summarize what a live DataHub user would do next.
